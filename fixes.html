Fixed Individually

Not “improved compatibility”. Real games that did not work, the exact fault, and the fix. Nothing needs configuring, it goes on when the game launches.

01_named_faults

OutRun 2006: Coast 2 Coast

A white screen. It seems to hang on the SEGA logo, so it gets killed.

The intro is a run of video logos, and under a compatibility layer the first can sit there a minute or more. Not frozen, but nobody waits that long. The intro is now skipped.

The community patch installs under a filename Wine replaces with its own, so it never loaded. The game’s own copy now wins, as on Windows.

Resident Evil 2 · Biohazard 2 (Classic REbirth)

Comes up untranslated and stops dead at a Japanese error box.

The patch is a graphics library beside the game, and Wine loaded its own instead, so it never ran. The game’s own copy is now loaded first, with Wine’s behind it as a fallback.

The fallback is the trick: the patch passes what it doesn't implement through to the real library. With nothing behind it, the game crashes instantly.

Quake (GOG), the Windows builds

GLQuake and both mission packs close instantly. No window, no error.

GOG ships a 3dfx driver from the nineties, and Wine substituted its own, so the game died before a window appeared. The driver GOG shipped is now used.

Fallout: New California

“Fallout: New Vegas does not appear to be installed.” Please insert the DVD.

Every file downloaded perfectly, but GOG’s installer performs three finishing steps afterwards and nothing on Linux did them. Now applied at launch, repairing the install you have. No reinstall.

Realms of Arkania 1 & 2 · Albion

DOSBox opens for half a second, then vanishes.

Two faults. The configuration files GOG’s installer copies were never copied, and the game started from the wrong folder, so DOSBox looked one level too high and quit. Both fixed.

Colony Ship

Stuck at 50.5% for an hour. Downloading fast. Getting nowhere.

One file was damaged on a GOG server. Half arrived, the connection closed, every time, and the download kept asking that same server. Now each piece is checked and a different server is used when one keeps failing.

02_why_a_list

why keep a list like this at all

Most of what goes wrong is solved by a general rule, and those are part of the app. What's left belongs to one game and nothing else. Each costs an evening. Writing them down is the least I can do.

The list will grow. A game on it behaves on your machine the way it did on mine.
