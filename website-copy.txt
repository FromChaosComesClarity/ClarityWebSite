CLARITY — ALL WEBSITE COPY
=================================

Every word on the site, in one file. Rewrite anything below in your own voice and hand it
back; it goes straight into the pages.

HOW TO EDIT
-----------
  * Change the text UNDER a "###" line. Never change the "###" line itself — that is the
    address the text goes back to.
  * A block can be as many lines as you like. It ends at the next "###".
  * To delete a piece of copy, leave the block empty.

FORMATTING YOU CAN USE
----------------------
  **bold**            *italic*            `code`            [link text](page.html)

Anything else — an &mdash;, a <br>, an emoji — just leave as you find it.

WHAT THE LABELS MEAN
--------------------
  title             the browser tab and Google's headline
  meta:description  the sentence under it in search results
  og:title / og:description   what appears when the link is pasted into chat
  001, 002, ...     a piece of copy on the page, in the order you read it
  h1 h2 h3          headings, largest first
  p                 a paragraph      li  a bullet      figcaption  a caption under a picture
  div span a        short labels, tags and link text

### fixes.html | 009 | h1

### fixes.html | 010 | p
Not &ldquo;improved compatibility&rdquo;. Each of these is a real game that did not work on Linux, the exact thing that turned out to be wrong with it, and what is now done about it automatically. **Nothing here needs to be configured** &mdash; the fix is applied when the game is launched.

### fixes.html | 011 | div
01_named_faults

### fixes.html | 012 | h3
OutRun 2006: Coast 2 Coast

### fixes.html | 013 | div
A white screen. It seems to hang on the SEGA logo, so it gets killed.

### fixes.html | 014 | p
The intro is a run of video logos, and under a compatibility layer the first one can sit there for a minute or more before the menu ever arrives. It is not frozen &mdash; but nobody waits that long, and nobody should have to. **The intro sequence is now skipped**, which removes both the wait and the thing that stalls in it.

### fixes.html | 015 | p
The community patch this relies on installs itself under a filename Wine replaces with its own version, so it was never being loaded to begin with. **The game&rsquo;s own copy now wins**, which is what happens on Windows.

### fixes.html | 016 | h3
Resident Evil 2 &middot; Biohazard 2 (Classic REbirth)

### fixes.html | 017 | div
Comes up untranslated and stops dead at a Japanese error box.

### fixes.html | 018 | p
The Classic REbirth patch is a graphics library that sits beside the game, and Wine was loading its own version instead &mdash; so the patch never ran at all. **The game&rsquo;s own copy is now loaded first**, with Wine&rsquo;s kept behind it as a fallback.

### fixes.html | 019 | p
That fallback is the whole trick: the patch passes anything it does not implement itself through to the real library, and with nothing behind it the game crashes instantly instead.

### fixes.html | 020 | h3
Quake (GOG) &mdash; the Windows builds

### fixes.html | 021 | div
GLQuake and both mission packs close instantly. No window, no error.

### fixes.html | 022 | p
GOG ships this with a 3dfx graphics driver from the nineties, and the same shadowing problem applied: Wine substituted its own, and the game died before a window appeared. **The driver GOG shipped is now used**, which is the stack the release was built around.

### fixes.html | 023 | h3
Fallout: New California

### fixes.html | 024 | div
&ldquo;Fallout: New Vegas does not appear to be installed.&rdquo; Please insert the DVD.

### fixes.html | 025 | p
Every file downloaded perfectly &mdash; but GOG&rsquo;s installer normally performs three finishing steps afterwards, and nothing on Linux was doing them. **Now applied at launch**, repairing an install you already have, no reinstall.

### ports.html | 117 | h2
why a catalogue, and not an importer

### ports.html | 118 | p
A general importer has to guess: which file in the archive is the game, where the data lives, what the launch line needs to say. Guessing is how a mod pack installs a voice pack, how a sequel ends up under the first game's name, and how a port lands perfectly and then opens and closes in the same second.

### ports.html | 119 | p
A recipe does not guess. It knows what the download is called, which executable is the real one among the six in the folder, which file proves a folder really is Quake, and what has to be true before a single byte is unpacked. That is worth writing down once per project, and it is why this is a list &mdash; twenty-five today, and growing one entry at a time.
