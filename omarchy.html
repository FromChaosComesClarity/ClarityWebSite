What it does only here

Clarity should run on any Linux desktop. But it's built for, tested on and tailored to Omarchy, and there are four things it does here that it can't do anywhere else.

01_the_launcher

Your whole library, one shortcut away

Bind a key. Type three letters of a game's name. Press Enter. It plays. No window opening first, nothing to click. This is the feature I use more than any other.

It searches your games and the app's own actions in one list, so “quake” and “storage” are the same gesture. Games you own but haven't installed show up too. Pressing Enter opens the page with the Install button on it, instead of quietly doing nothing at you.

The overlay never launches anything itself. It asks the app. That way a launch keeps the store picker, the “which engine?” and “which Doom?” questions, and the install check, exactly as if you'd pressed Play yourself.

02_the_bar

A widget that knows what you're playing

Installed count when nothing's running, the game's name when something is. Click it for a menu one step from the library, the big screen face, Manage Storage and the Control Panel.

  • What's playing comes from the compositor, not the app. Clarity launches a game and gets out of the way. It usually isn't running while you play, so asking it would give the wrong answer for exactly the case the widget exists to show.
  • Nothing to configure. The app writes down where it lives and the widget reads that. No paths to type.
  • It's honest when it can't help. If the app isn't there you get a bare mark and an offer to fetch it. Never a wrong number.
03_the_theme_bridge

It wears the theme you already chose

Clarity uses the theme Omarchy is using right now. Install a new one, apply it, and the app is wearing it too. The same colours, not an approximation of them.

The 93 themes that ship with the app are still there if you'd rather have one of those. Both faces draw from the same set, so a look you like on the desktop follows you to the big screen.

04_games_open_properly

Fullscreen, on the right screen

Under a tiling window manager a game normally gets squeezed into whatever slot the layout has free and resized, a second before it goes fullscreen anyway. Here games open fullscreen from the first frame, on the monitor you picked, at the resolution you expect.

  • Floating and tiled are still there, for a game whose launcher window needs to stay small.
  • Changes take effect when you ask, not at your next login.
  • The screen you choose is remembered, and games arrive there every time.
05_the_plugin

Getting it

The bar widget and the launcher are a companion plugin, about nine kilobytes of code, with no library, no launcher and no games of its own, so it needs Clarity installed. Without it, it says so and offers to fetch it, in a terminal you can watch.

⚠ Not published yet

The plugin is built and in daily testing, but it isn't on Omarchy's plugin marketplace yet. It goes out with 2.0.
