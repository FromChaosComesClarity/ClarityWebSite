What it does only here

Cafe Neurotico should run on any Linux desktop. However it is built for, tested on and tailored for Omarchy, and there are four things it can do there that it cannot do anywhere else.

01_the_launcher

Your whole library, one keyboard shortcut away

Bind a key. Type three letters of a game's name. Press Enter. It plays — with no window opening first, and nothing to click.

It searches your games and the app's own actions in one list, so “quake” and “storage” are the same gesture. Games you own but have not installed appear too — pressing Enter opens the page where the Install button is, instead of quietly doing nothing.

Nothing is launched by the overlay itself. It asks the app, which means a launch keeps the store picker, the “which engine?” and “which Doom?” questions, and the install check — exactly as if you had pressed Play.

02_the_bar

A widget that knows what you are playing

Installed count when nothing is running; the game's name when something is. Click it for a menu one step from the library, the big screen face, Manage Storage and the Control Panel.

  • What is playing comes from the compositor, not the app. Cafe Neurotico launches a game and gets out of the way — it is usually not running while you play, so asking it would give the wrong answer for exactly the case the widget exists to show.
  • Nothing to configure. The app writes down where it lives; the widget reads that. No paths to type.
  • It lets you know. If the app is missing, you get a bare cup and an offer to fetch it — never a wrong number.
03_the_theme_bridge

It wears the theme you already chose

Cafe Neurotico uses the theme Omarchy is currently using. Install a new theme, apply it, and the app is wearing it too — the same colours, not an approximation of them.

The 93 themes that ship with the app are still there if you want one of those instead. All three faces draw from the same set, so a look you like on the desktop mode follows you to the big screen mode.

04_games_open_properly

Fullscreen, on the right screen

Under a tiling window manager a game would otherwise be fitted into whatever slot the layout has free and resized — a second before it goes fullscreen anyway. Games open fullscreen from the first frame, on the monitor you picked, at the resolution you expect.

  • Floating and tiled are still there, for a game whose launcher window needs to stay small.
  • Changes take effect when you ask, rather than waiting for your next login.
  • The screen you choose is remembered, and games arrive there every time.
05_the_plugin

Getting it

The bar widget and the launcher are a companion plugin. It is around nine kilobytes of code — no library, no launcher and no games of its own — so it needs Cafe Neurotico installed. Installed without it, it says so and offers to fetch it, in a terminal you can watch.

⚠ Not published yet

The plugin is built and in daily testing, but it is not on Omarchy's plugin marketplace yet. It goes out with 2.0.
