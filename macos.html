macOS

Apple Silicon · macOS 11 or later

The Mac edition is its own thing now. It forked from the Linux app at 1.15.3, it lives in its own repository, and from here the two are allowed to grow apart. That is exactly what I want: this one gets to be great on Omarchy, and the Mac one gets to be great on a Mac.

It has its own releases, and their notes are the place to read what it does today.

01_how_it_differs

how it differs

✓

Windows games go through CrossOver

Proton is a Linux thing. On the Mac, Windows games run through CrossOver, which is commercial software from CodeWeavers and not bundled, so you install it yourself.

✓

Native first, wherever a native build exists

Real macOS builds win when there are any: native GOG installs, source ports like GZDoom, vkQuake, ECWolf and EDuke32, and Fallout 1 and 2 Community Edition, all reading game data you already own.

✓

Two Steam clients, and it asks

With CrossOver in the picture a Mac has two Steams, the Mac app and the Windows one inside a bottle. When a game ships both builds, Clarity asks which one you want instead of guessing.

02_install

install

These builds aren't notarised, so macOS refuses to open one the first time, and it does not offer a way around it.

  1. Download the .dmg (or the .zip) from the latest release.
  2. Open the .dmg and drag Clarity into Applications.
  3. Skip right-click → Open and System Settings. There is no Open Anyway button for these builds, and Apple removed the right-click bypass in macOS 15. From Terminal instead: xattr -dr com.apple.quarantine "/Applications/Clarity Game Manager.app" Once per install. Every release repeats this command in its notes, so there is nothing to remember.
