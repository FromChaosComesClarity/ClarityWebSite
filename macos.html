macOS

same codebase · Apple Silicon

Linux stays primary: tested first, ships fastest. The macOS build is in the same codebase, not a fork, and it's real: Steam and GOG sign-in, the full library, installing and launching games.

current macOS build: 1.13.1, attached to the 1.14.0 release. The Mac cannot be packaged from Linux, so it runs a version behind and has no Manage Storage buttons yet.

01_what_works_today

what works today

✓

The full library

Steam and GOG sign-in, sync and browsing, across both faces, with Installer underneath.

✓

Native GOG installs

Real downloads through gogdl, for games that ship an Apple Silicon build. Not a link out to a browser.

✓

Windows games, through CrossOver NEW IN 1.9

Windows-only titles aren't off-limits. Clarity drives CrossOver directly, giving each game its own bottle, created on first launch and reused. Nothing to configure.

Two caveats. CrossOver is commercial software from CodeWeavers, not bundled, so you install it yourself. Without it this reports as unavailable. The plumbing is verified, but I have not run a big library through it.

✓

Knowing which games are actually native

A Mac-Native filter next to the store filters, with an apple badge on the cover. GOG is instant. Steam needs one manual scan, it's a live per-game lookup.

✓

Everything that is not platform-specific

Artwork, genres, playlists, save backups, themes. Almost all of it is the same code that runs on Linux.

02_not_yet

what doesn't work yet

▸

Epic sign-in

The browser approval completes, but the credentials aren't written where legendary looks, so the sync comes back empty. Steam and GOG are unaffected. Treat macOS as Steam and GOG for now.

▸

Anti-cheat

BattlEye and EAC aren't wired up. CrossOver claims support for both, but nothing here has been tested against a game that uses them. Assume anti-cheat multiplayer won't run.

▸

A picker for which screen a game opens on

A KDE-only feature on Linux. There's no macOS equivalent yet.

▸

Custom installers, source ports and mods

The whole recipe catalogue, Ironwail, GZDoom, the Build-engine games, is Linux-only for now.

03_install

install

The build isn't signed, there's no Apple Developer account behind it yet, so the first launch needs one extra step. Standard for anything unnotarized, not a sign something is broken.

  1. Download Clarity-1.13.1.dmg (or the .zip) from the latest release. It sits beside the Linux AppImage, and its filename carries its own version.
  2. Open the .dmg and drag Clarity into Applications (or unzip and move the .app there directly).
  3. Right-click (or Control-click) the app → Open → Open works on most macOS versions. If that option doesn't appear, double-click once to get blocked, then System Settings → Privacy & Security and Open Anyway.
  4. If neither works, from Terminal: xattr -dr com.apple.quarantine "/Applications/Clarity Game Manager.app" This strips the quarantine flag. Once per install.
