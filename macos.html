macOS

same codebase · Apple Silicon

Linux stays the primary platform. It's what gets tested first and ships fastest. The macOS build lives behind its own file in the same codebase rather than a fork, and it's real rather than a proof of concept: Steam and GOG sign-in, the full library, and installing and launching games.

current macOS build: 1.13.1, attached to the 1.14.0 release alongside the Linux AppImage. The Mac cannot be packaged from Linux, so it runs a version behind and does not have the Manage Storage buttons yet.

01_what_works_today

what works today

✓

The full library

Steam and GOG sign-in, sync and browsing, across both faces, the Manager and Couch Mode, with Installer working underneath them.

✓

Native GOG installs

Real downloads through gogdl directly, for games that ship an Apple Silicon build. Not a link out to a browser.

✓

Windows games, through CrossOver NEW IN 1.9

Titles that only ship a Windows build aren't off-limits any more. Clarity drives CrossOver directly, giving each game its own bottle under the same per-game scheme the Linux build already uses. Created once on first launch, reused after that. Nothing to configure.

Two honest caveats. CrossOver is commercial software from CodeWeavers and isn't bundled, so you install it yourself, and without it this simply reports as unavailable. And while the plumbing is verified, I haven't put a big library of Windows games through it yet.

✓

Knowing which games are actually native

A Mac-Native filter sits next to the store filters in the library, with a small apple badge on the cover art of anything that qualifies. GOG is checked instantly from data the app already has. Steam needs one manual scan, since that's a live per-game lookup.

✓

Everything that is not platform-specific

Artwork, genres, playlists, save-game backups, themes, all of it. Almost all of the app is the same code that runs on Linux.

02_not_yet

what doesn't work yet

▸

Epic sign-in

Signing in to Epic doesn't hold on macOS yet. The browser-based approval completes, but the credentials aren't written where legendary looks for them, so the library sync comes back empty. Steam and GOG are unaffected. I'm working on it. Until it lands, treat macOS as Steam and GOG only.

▸

Anti-cheat

BattlEye and EAC aren't wired up. CrossOver advertises its own support for both, but nothing here has been tested against a game that uses them, so assume multiplayer titles relying on anti-cheat won't run.

▸

A picker for which screen a game opens on

A KDE-only feature on Linux. There's no macOS equivalent yet.

▸

Custom installers, source ports and mods

The whole recipe catalogue, Ironwail, GZDoom, the Build-engine games and the rest, is Linux-only for now.

03_install

install

The build isn't signed, because there's no Apple Developer account behind it yet, so the first launch needs one extra step. That's the standard cost of an app that hasn't gone through notarization, not a sign something is broken.

  1. Download Clarity-1.13.1.dmg (or the .zip) from the latest release. The macOS build sits beside the Linux AppImage there, and its filename carries its own version, because the two hosts are not always on the same number.
  2. Open the .dmg and drag Clarity into Applications (or unzip and move the .app there directly).
  3. Right-click (or Control-click) the app → Open → Open still works on most macOS versions for the first launch. If that option doesn't appear, a normal double-click gets blocked once, so go to System Settings → Privacy & Security and click Open Anyway.
  4. If neither shows anything, from Terminal: xattr -dr com.apple.quarantine "/Applications/Clarity Game Manager.app" This strips the quarantine flag macOS attaches to anything downloaded from the internet. It only needs doing once per install.
04_where_things_live

where things live

Everything is under ~/Library/Application Support/. Deleting the app and installing a new build never touches the library.

WhatWhere
Your library (games, artwork, playlists, settings)Clarity/GameManagerConfig/
GOG/Epic install state, auth, launch logsClarity/InstallerConfig/
Installed games (default location)~/Games/Clarity/
